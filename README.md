### 🎣 Phishing URL Detection System (PFA @ CMRPI)
A complete early-warning system for phishing, aimed at SMEs.

- Ensemble model: Random Forest (20 structural features) + TF-IDF / Logistic Regression, **96.91% accuracy on 651,191 URLs**
- Three-layer decision pipeline: blacklist → whitelist of 528 trusted domains → ML
- Flask REST API (9 endpoints), URLhaus threat-intel integration, SMTP alerting with URL defanging and 24h deduplication
- React dashboard styled as an "Analyst Workstation"
